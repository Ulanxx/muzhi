很多人兴冲冲想试试 AI 工具，结果第一步就卡住了——不是卡在 AI 多难，而是卡在那个黑乎乎的**命令行窗口**。

## 命令行没那么可怕

命令行就是**用打字代替点鼠标**。你在图形界面里双击一个文件夹，命令行里对应的是：

```bash
cd my-folder
```

你在图形界面里新建一个文件，命令行里对应的是：

```bash
touch my-file.txt
```

没有魔法，只有对应关系。

## 新手只需要先记住五个命令

| 命令 | 作用 | 类比 |
|------|------|------|
| `pwd` | 我现在在哪个文件夹 | 看看当前位置 |
| `ls` | 这个文件夹里有什么 | 打开文件夹看一眼 |
| `cd` | 进入某个文件夹 | 双击进入 |
| `mkdir` | 新建文件夹 | 右键新建 |
| `clear` | 清空屏幕 | 把桌面擦干净 |

就这五个，够你跟着绝大多数 AI 工具的教程走下来了。

## 一个真实场景

假设教程让你"进入项目目录并启动"：

```bash
cd my-ai-project
npm run dev
```

拆开看就是两步：**先走进那个文件夹**（`cd`），**再执行启动命令**（`npm run dev`）。如此而已。

下次再看到黑窗口，别关。它就只是个更直接的操作方式而已。
